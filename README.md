# Healthcare & Hospital Management Database System

## Overview
A relational database system designed using MySQL and Python to streamline hospital operations, including patient registration, doctor schedules, and billing calculations.

## Features
- **Patient Management:** Store and retrieve patient records efficiently.
- **Doctor Schedules:** Manage appointment slots and doctor availability.
- **Billing System:** Calculate total treatment expenses using SQL queries.

## Tech Stack
- **Database:** MySQL
- **Programming Language:** Python
- **Connector:** `mysql-connector-python`

## Key Queries Used
- `JOIN` operations to link patient and doctor data.
- `GROUP BY` and aggregate functions for financial reporting.
